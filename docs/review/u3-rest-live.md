major | src/main/java/de/is4it/midpoint/diff/MidpointRestClient.java:241 | `retryable` is `"GET".equals(request.method())`, but the object read is no longer a GET — `LiveLookup` resolves every current object through `POST {type}/search`, so `--retries N` does not cover the tool's primary read. ## Checked and found sound

- **Auth handling.** The `Authorization` header is built once and never logged: `--trace` logs request/response
  *bodies* and `--debug` logs the URI, never headers. Basic auth is sent preemptively on every request (no 401
  round-trip), and `resolvePassword`'s precedence matches DESIGN; `console.readPassword` does not echo.
- **Non-interactive password prompt.** `System.console() != null` is still a valid interactivity test here:
  verified that Temurin 17/21/25/26 all return `null` with redirected stdin, so a piped `midgie diff - --url …`
  cannot have its stdin XML eaten as the password, and the "no password provided" error is reached instead.
- **Redirects.** `HttpClient`'s default policy is `NEVER`, so no 3xx is followed and the `Authorization` header
  cannot be replayed to another host; the 3xx branch reports the `Location` with a context-path hint.
- **Retry safety.** Only 502/503/504 and connect/timeout are retried, never a 4xx; writes are excluded
  (test-covered at `MidpointRestClientTest:190`), and `backoff` restores the interrupt flag.
- **Search-based existence check.** midPoint's `POST /{type}/search` (`ModelRestController:633`) applies no
  default paging, so `LiveLookup.byName`'s `matches.size() > 1` ambiguity guard sees every match rather than a
  truncated first page.
- **`--cacert`.** Builds a trust store from exactly the supplied PEM (chain-verifying, hostname verification
  intact) and fails fast with a wrapped message on an unreadable/non-certificate file.
- **URI construction.** `restBaseOf` is idempotent for a trailing `/` and an already-`/ws/rest` URL; the
  `?include=` query values are `URLEncoder`-escaped; REST type names come from `ObjectTypes`, not user input.
