## Checked and clean (so the next reviewer does not redo it)

- **No other order-dependent class.** All 20 non-rig test classes were run individually (`-Dtest=<Class>`); only `PolicyTest` fails alone. The other 11 classes that need prism each bootstrap their own context in `@BeforeAll`.
- **Rig gating is honest.** `LiveIntegrationTest` uses `assumeTrue(rigUp, …)` in every test and cleans its fixed OIDs before *and* after; `reachable()` is a real `GET` of the administrator. With the rig up, all 13 run and pass; nothing in the class can pass while the rig is down.
- **The antrun MP_VER guard works.** `docker/.env` **is** tracked (`git ls-files docker/.env`), so `<loadproperties>` always has a file in a clean clone; a drift fails the build in `validate`, before any compilation. The relative `srcFile` resolves against `${basedir}`, correct for this single-module build.
- **CHANGELOG extraction.** The awk block was run against the real file for `0.3.1`, `0.3.0`, `0.1.0` (correct section, stops at the next `## [` or the link block) and for `0.3.11` / `9.9.9` / `0.3.1-rc1` (empty → the `[ ! -s ]` fallback at :58 fires). No malformed-tag hole: the two `on.push.tags` patterns cannot admit a tag `${GITHUB_REF_NAME#v}` would turn into an invalid Maven version.
- **Shade packaging.** No signature files, no `INDEX.LIST`, service files merged, main class set, `finalName=midgie` so the release `cp target/midgie.jar` is stable across `versions:set`. The 54 `META-INF/versions/**` entries with no `Multi-Release: true` are all optional accelerators (jackson fast-double-parser, logback console charset, spring virtual threads, snakeyaml logger) — none is on midgie's path, so it is not worth a finding.
- **TLS sub-rig.** Private keys and certs are git-ignored and generated (`docker/.gitignore`, `gen-certs.sh`); nothing secret is committed. `run-tls-tests.sh` exits non-zero when the server never comes up (2 of its 5 checks then fail), so it cannot silently pass against a dead proxy.
- **Test substance.** No test asserts only on its own fixture: `GoldenOutputTest` pins against a committed golden, `DiffCommandTest` asserts delta *shape* (which item, replace vs add/delete, which value) with real controls for every scope/multivalue/equivalence claim, `MidpointRestClientTest` asserts the wire (method, path, auth header, retry counts) against a stub, and `DeployCliTest` drives the real `Main` and asserts exit codes plus ordering.
